# Verify Skills

Every `skills/*/SKILL.md` and `docs/skills.md` is generated by `gwsr dev generate-skills` from the CLI's own command tree and `crates/gws-rust/registry/{personas,recipes}.toml`. Never edit a SKILL.md by hand: fix the help text, the registry or `crates/gws-rust/src/generate_skills.rs`, then regenerate.

## Steps

1. **Regenerate and check for drift**

// turbo
```bash
just skills && git status --short skills docs/skills.md
```

The summary's `pruned` lists generated skills that were deleted because they are no longer produced. Anything under `unmanaged` lacks the generator marker: delete it by hand if it is stale.

```bash
grep -L 'gwsr generated skill: do not edit by hand' skills/*/SKILL.md   # must print nothing
```

2. **List every service, method and helper with its flags**

// turbo
```bash
./target/debug/gwsr commands --format table
```

3. **Spot-check the method paths used in examples**

// turbo
```bash
./target/debug/gwsr drive files --help
./target/debug/gwsr gmail users messages --help
./target/debug/gwsr sheets spreadsheets values --help
./target/debug/gwsr calendar events --help
./target/debug/gwsr admin users --help
```

4. **For each SKILL.md, check:**

   - [ ] Resource and method names and nested paths match `gwsr commands` exactly
   - [ ] Examples use valid `--params` / `--json` JSON and current helper flags (`--<noun>-id`, `--output`, `--limit`)
   - [ ] Destructive examples include `--yes` or are shown with `--dry-run`
   - [ ] The service alias and API version in the header match `crates/gws-rust-core/src/services.rs`

5. **Check `skills/gwsr-shared/SKILL.md` covers:** auth (`gwsr auth login`, `GWSR_TOKEN`, `GWSR_CREDENTIALS_FILE`, `--profile`), the global flags, `--fields`, pagination (`--page-all`, `--page-items`, `--page-limit`), `gwsr schema` and `gwsr commands`, the stderr error envelope and exit codes 0-11, `--output`/`--upload`, `--wait`, and `-y/--yes`.

6. **Registry recipes are also checked by tests:** `cargo test -p gws-rust registry_tests` parses every command in `registry/*.toml` against the real command tree.
